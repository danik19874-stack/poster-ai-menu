# Сценарий демо-видео/GIF для Poster Marketplace

Нужно два разных материала (Poster требует оба, см. `marketplace-instructions-ru.md`
и живую проверку `dev.joinposter.com/en/docs/v3/market/release`):

1. **Видео для модерации** (прикладывается ссылкой в поле "Update Note" при
   подаче на проверку) — можно неформально, хоть на телефон, важно чтобы
   было видно весь сценарий целиком.
2. **GIF для публичной инструкции** в карточке — короче, чище, без лишних
   пауз, показывает только «как подключить» и «как этим пользуется гость».

Инструменты (бесплатно, без консоли): **Win+G** (Xbox Game Bar, уже в
Windows 11) — для записи экрана телефона через приложение "Ваш телефон"
или простого скрин-каста браузера; **ScreenToGif** — для записи + обрезки
+ экспорта в GIF одним приложением.

---

## Кадр 1 — Подключение (владелец)

1. Открыть карточку приложения в каталоге Poster.
2. Нажать «Подключить заведение».
3. Poster запрашивает разрешение — нажать «Разрешить».
4. Автоматический переход на страницу `/connected` — показать, что там
   сразу видно название заведения и готовый QR-код.

**Что важно показать:** ничего не пришлось настраивать вручную, меню уже
подтянулось из кассы.

## Кадр 2 — QR-коды на столы (владелец)

1. На странице `/connected` ввести номер стола (например, 5).
2. Нажать «Скачать QR (PNG)» — показать, что скачался файл.
3. Быстро показать: поменяли номер на 6 → QR обновился на экране без
   перезагрузки.

## Кадр 3 — Гость сканирует QR (с телефона)

1. Реальным телефоном отсканировать QR-код камерой.
2. Открывается меню — показать прокрутку по категориям, фото блюд, цены.

## Кадр 4 — Вопрос ИИ про состав/аллергию

1. Открыть карточку блюда.
2. Показать приветствие ИИ («Добро пожаловать в [Заведение]...»).
3. Задать вопрос в духе «есть аллергия на молоко, что можно?».
4. Показать ответ — что ИИ честно называет только безопасные блюда.

**Это ключевой кадр** — именно то, чего нет в бесплатном QR-меню Poster,
ради этого весь ролик.

## Кадр 5 — Рекомендация на компанию

1. Вернуться в общее меню.
2. В блоке «Не знаете, что выбрать?» задать вопрос «посоветуйте на
   компанию из 3 человек».
3. Показать ответ с конкретными блюдами из настоящего меню.

## Кадр 6 — Заказ и подтверждение у официанта

1. Добавить 1–2 блюда в корзину.
2. Оформить заказ (кнопка в корзине).
3. Переключиться на экран кассы Poster (или POS-терминал) — показать, что
   заказ появился мгновенно.
4. Официант подтверждает заказ одним нажатием.

**Что важно показать:** заказ не уходит на кухню в обход персонала —
финальное решение всегда за официантом.

## Кадр 7 (опционально, для видео на модерацию, не для публичного GIF)

Показать `/admin`: сколько заказов пришло сегодня, сколько столов активно.
Это не для гостей и не для публичной инструкции — просто чтобы модератор
Poster увидел, что у приложения есть рабочая аналитика.

---

## Тайминг

- Публичный GIF: 15–25 секунд, без звука, кадры 1–4 (самое важное —
  подключение + вопрос про аллергию).
- Видео для модерации: 1–2 минуты, кадры 1–6 полностью, можно с голосовым
  комментарием на ходу — не нужно готовить студийную озвучку, Poster сам
  пишет, что видео можно записывать неформально, лишь бы было понятно.
